# Agents.md

## Test-driven Development (TDD)

Follow Test-driven development. Write tests before writing code. Validate that all tests fail. Begin to write functions against those tests until the assumed expectations are passing.

## Branching

Check out a branch off main. Work on the new feature, committing small changes along the way. Open a pull request. Once human review approves, squash all the commits for that feature and then rebase onto trunk.
